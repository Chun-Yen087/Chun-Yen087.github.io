A full-stack scheduling app for a retail store. Managers build and publish weekly schedules, staff set availability and request time off, and shift swaps go to a manager for approval.

Tools & methods
React 18, TypeScript, Tailwind CSS, Vite, Node.js, Express, PostgreSQL 16, Prisma ORM, JWT auth, Zod, Vitest, Docker Compose
Skills
Full-stack development, relational data modeling, REST API design, role-based access control, automated testing
My role
Designed and built the full stack: database schema, API modules, conflict-detection engine and the React interface
Outcome
A conflict engine checks every assignment against 8 rules (overlaps, rest time, max hours, availability, time off, role fit) and flags each as a hard block or a warning. Key actions are written to an audit log, and the whole app runs with one Docker command.
